# TTS Announce Card

A Lovelace custom card for sending TTS announcements to your media players.

## Features

- Popup modal with message, volume, voice, and speaker selection
- 10 built-in Edge TTS voices
- Configurable speakers
- HA theme aware — matches any dashboard theme
- No external dependencies — one JS file, zero config required

## Install

1. Add this repository in HACS → Custom repositories
2. Install "TTS Announce Card"
3. Add `type: custom:tts-announce-card` to any dashboard
4. Also install: **Chime TTS** + **Edge TTS** from HACS
